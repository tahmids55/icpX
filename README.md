## Overview
ICPX provides tools for tracking programming contests, managing problems, syncing data across devices, and more. It includes:
- An Android app for mobile users
- A Desktop Java application for advanced features

## Features
### Android App
- Firebase integration for cloud sync
- Modular code structure
- Rich UI with layouts, drawables, and animations
- Gradle build system
- Cloud sync and documentation

### Desktop App
- Java desktop application (JavaFX)
- Modular MVC structure
- Maven build and dependency management
- Rich UI with FXML views
- Database integration
- Cloud sync and authentication services

## Setup & Installation
### Android
1. Open the `Android` folder in Android Studio.
2. Configure Firebase using `google-services.json`.
3. Build and run the app using Gradle.

### Desktop
1. Open the `Desktop` folder in your IDE (IntelliJ IDEA recommended).
2. Build using Maven (`pom.xml`).
3. Run the main application class.
